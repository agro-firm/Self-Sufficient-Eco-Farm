## Main capacity/output snapshot

- Open beds ~2,500–3,000 m²
- Greenhouse/protected crop ~700–1,000 m²
- Nursery/mother plants ~250–350 m²
- Annual mixed-vegetable output target 8–15 t
- Mixed vegetables: 8–15 t/year planning
- Nursery seedlings for own farm plus optional sale
- Protected crop smooths seasonal supply
- Possible crops: tomato, brinjal, chili, okra, gourds, leafy greens, onion/garlic/herbs

## Required rule

Do not judge this space only by cash income. Some zones create direct sales, some create internal replacement value, and some protect the rest of the farm by reducing risk or operating cost.

See [farm-wide economic assumptions](../../docs/ECONOMIC_ASSUMPTIONS.md).
