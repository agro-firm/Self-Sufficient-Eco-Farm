## Main capacity/output snapshot

- Continuous perimeter fire/service ring ~4.9 m average width
- Main clean gate ~6 m clear
- Service/emergency gate ~5 m clear
- Connects all critical zones for maintenance and emergency access
- No sale output
- Service output: transport access, emergency response, maintenance access, lower internal hauling time

## Required rule

Do not judge this space only by cash income. Some zones create direct sales, some create internal replacement value, and some protect the rest of the farm by reducing risk or operating cost.

See [farm-wide economic assumptions](../../docs/ECONOMIC_ASSUMPTIONS.md).
