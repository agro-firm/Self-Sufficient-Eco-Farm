# Blueprint & Drawing Set

Minimum drawing package for this space:

- **A-001** residential site plan / space management
- **A-101** ground-floor plan
- **A-102** first-floor plan
- **A-103** roof + solar plan
- **A-201–204** north/south/east/west elevations
- **A-301+** building sections
- **G-101** garage/parking/vehicle movement
- **P-101** potable/cold/hot/rainwater plumbing
- **D-101** stormwater/roof/yard drainage
- **S-101** sanitary blackwater/greywater routing
- **POOL-101** pool layout, barrier, plant and drain routes
- **E-101** power/sub-main/critical circuits
- **E-102** lighting/daylight controls
- **ELV-101** CCTV/data/access/intercom
- **F-101** fire/life-safety/egress/emergency assembly
- **L-101** playground, pool deck, hardscape, pervious buffers

All unengineered dimensions and equipment ratings remain PROVISIONAL.
