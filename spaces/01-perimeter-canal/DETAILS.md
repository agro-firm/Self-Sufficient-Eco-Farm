# Perimeter Canal — Detailed Description

## What this space does

- fish production
- flood/stormwater retention
- irrigation reserve
- fire-water reserve
- security separation

## Why it is placed here

Treat the canal as a hydraulic/security ring first and an aquaculture system second. Maintain continuity, inspection access, fish escape control and overflow capacity.

## Interfaces

### Required / useful neighbors
- Security wall/inspection band outside
- Perimeter fire/service road inside
- Gate/bridge crossings at approved access points

### Controlled / prohibited interfaces
- raw human sewage
- raw manure or poultry wastewater
- oily workshop water
- untreated processing wastewater

## Utility dependencies

- screened irrigation intake
- fire-water suction points
- aeration/monitoring points
- sluice/screens/hapa management
- overflow/spillway

## Drainage / wastewater principle

Only controlled clean runoff after silt/erosion treatment may enter.

## Main risks

- loss of allocated area to unrelated uses
- cross-contamination between clean and dirty systems
- flood/cyclone damage
- poor maintenance access
- unplanned utility crossings
- future expansion without feed/water/energy/waste capacity checks

## Verification checklist

- [ ] Area remains within parent allocation
- [ ] L1 position is unchanged
- [ ] Required access is clear
- [ ] Drainage path is explicit
- [ ] Power/water/data needs are explicit
- [ ] Fire/emergency access is explicit
- [ ] Neighbor conflicts are checked
- [ ] Image/blueprint matches the master plan
