# Quarantine and Emergency Reserve Space

## Precision authority

Use `docs/SPATIAL_DESIGN_STANDARD.md` and `docs/SPACE_REGISTRY.md`.
- Plot basis: 250,000 mm × 220,000 mm.
- Exact centimeter/mm values are allowed only when approved in the coordinate registry or an approved engineering drawing.
- Otherwise mark dimensions/coordinates `PROVISIONAL`.
- Never derive an exact dimension from a photorealistic image.

## Planning allocation

**1,000 m²**, concept envelope ~20×50 m.

## Requirements

- independent access
- animal unloading point
- isolation pens
- examination/handling
- dedicated tools
- feed/water
- separate waste/drain route
- boot/vehicle disinfection
- temporary emergency storage area

## Rule

New or suspect animals never enter main herds/flocks before health clearance.
