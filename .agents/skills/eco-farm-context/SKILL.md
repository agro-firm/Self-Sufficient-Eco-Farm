# Eco-Farm Context

## Apply when
Use before any non-trivial planning, engineering, production, procurement, operations, or design task.

## Authorities
1. `docs/MASTER_PLAN_SUMMARY.md`
2. `docs/DECISIONS.md`
3. `SPACE.md`
4. `docs/SPATIAL_DESIGN_STANDARD.md`
5. `docs/SPACE_REGISTRY.md`
6. Relevant specialized skills

## Workflow
1. Identify the requested system and affected zones.
2. Confirm whether the task changes land allocation, resource flows, animal capacity, utilities, safety, or accepted decisions.
3. List required evidence: survey, soil, water, flood, weather, load, feed, manure, market, or health data.
4. Separate concept assumptions from verified values.
5. Select the smallest relevant skill set.
6. Identify dependencies and cross-zone impacts.
7. Run `eco-farm-quality-gate` before final acceptance.

## Guardrails
- Never treat concept dimensions as construction-ready.
- Never silently change the 5.5 ha basis or create a separate fish pond.
- Never trade crop sunlight, biosecurity, flood capacity, or clean/dirty separation for appearance.
- Specialist safety work remains subject to qualified professionals.
