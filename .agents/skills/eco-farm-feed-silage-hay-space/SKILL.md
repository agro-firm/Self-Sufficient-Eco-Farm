# Feed Mill, Silage and Hay Space

## Precision authority

Use `docs/SPATIAL_DESIGN_STANDARD.md` and `docs/SPACE_REGISTRY.md`.
- Plot basis: 250,000 mm × 220,000 mm.
- Exact centimeter/mm values are allowed only when approved in the coordinate registry or an approved engineering drawing.
- Otherwise mark dimensions/coordinates `PROVISIONAL`.
- Never derive an exact dimension from a photorealistic image.

## Reserve rules

- ruminant roughage reserve: 60–90 days
- poultry/fish formulated feed reserve: 14–30 days

## Feed mill components

ingredient receiving, cleaning, grinding, micro-ingredient weighing, mixing, optional pelletizing, bagging, finished-feed storage.

## Silage

- sealed
- drainage-controlled
- traffic access for filling/removal
- located for short fodder-to-animal flow
- leachate controlled

## Hay

- raised/dry/ventilated
- fire-separated from workshop/hot work
- moisture checked
- rodent control

## Guardrails

Never mix species formulas casually. Never use moldy feed.
