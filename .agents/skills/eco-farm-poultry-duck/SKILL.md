# Poultry and Duck Systems

## Base concept
Layers 120–150; broilers 80–120/batch; ducks 60–80.

## Workflow
1. Keep layer, broiler, and duck systems physically separated.
2. Use all-in/all-out sanitation for broilers.
3. Maintain dedicated tools and footwear.
4. Route egg collection through a clean path.
5. Use a managed duck wet pad/trough; no separate fish pond.
6. Treat bird washwater before reuse/disposal.
7. Formulate feed for each class and stage.

## Guardrails
No raw poultry waste to the canal. Vaccines and medicines come from certified sources.
