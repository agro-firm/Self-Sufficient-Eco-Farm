# Grain Store and Rice Mill Space

## Precision authority

Use `docs/SPATIAL_DESIGN_STANDARD.md` and `docs/SPACE_REGISTRY.md`.
- Plot basis: 250,000 mm × 220,000 mm.
- Exact centimeter/mm values are allowed only when approved in the coordinate registry or an approved engineering drawing.
- Otherwise mark dimensions/coordinates `PROVISIONAL`.
- Never derive an exact dimension from a photorealistic image.

## Capacity concepts

- grain store: 10–20 t dry-grain equivalent base capacity; 25–40 t only for expansion/custom processing
- rice mill: ~100–200 kg paddy/hour base capacity; up to ~300 kg/hour only with justified external/custom throughput

## Required zones

receiving → weighing/moisture check → drying → grain storage → mill → rice/bran/husk/broken-rice separation → storage/dispatch.

## Rules

- food grain, feed grain, and seed grain physically identified/separated
- moisture monitoring
- rodent/insect management
- dust extraction/housekeeping
- rice bran and broken rice recovered for feed use
- husk route defined
- ignition/hot-work kept away from dust/fire load

Show process sequence, equipment footprints, access clearances, bag/pallet zones, ventilation/dust strategy, and fire separation.
