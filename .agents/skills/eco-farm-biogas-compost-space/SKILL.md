# Biogas and Compost Space

## Precision authority

Use `docs/SPATIAL_DESIGN_STANDARD.md` and `docs/SPACE_REGISTRY.md`.
- Plot basis: 250,000 mm × 220,000 mm.
- Exact centimeter/mm values are allowed only when approved in the coordinate registry or an approved engineering drawing.
- Otherwise mark dimensions/coordinates `PROVISIONAL`.
- Never derive an exact dimension from a photorealistic image.

## Planning allocation

**1,600 m²**.

Concept split:
- digester/equipment ~250–350 m²
- solids/equalization ~200 m²
- compost ~400–500 m²
- wastewater treatment ~250–350 m²
- service/buffer = balance

## Flow

manure/suitable organics → separation/equalization → digester → gas + digestate → treatment/maturation → soil/fertilizer use.

## Rules

- no untreated slurry to canal
- control odor/runoff
- gas equipment separated from ignition sources
- digestate nutrient-tested before application
- poultry litter dosing controlled
- compost leachate contained
