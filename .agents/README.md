# Eco-Farm Agent Skills

The skills in this folder are project-specific instructions for planning, drawing, reviewing, building, and operating the farm.

## Discovery order

1. `eco-farm-context`
2. relevant individual-space skill(s)
3. relevant system skill(s)
4. `eco-farm-precision-layout-visualization` for any drawing/image
5. `eco-farm-quality-gate`

## Why there are many skills

The farm is intentionally decomposed by physical space and system. Each skill owns its own geometry, adjacency, internal functions, utilities, drainage, safety, and visualization rules. This prevents one general-purpose agent from accidentally moving or mixing farm systems.

## Precision

Read:
- `docs/SPATIAL_DESIGN_STANDARD.md`
- `docs/SPACE_REGISTRY.md`
- `docs/IMAGE_BLUEPRINT_STANDARD.md`

Exact centimeter/mm dimensions are binding only after approval. Before that they must be marked provisional.

## Professional boundary

Skills orchestrate the project; they do not replace licensed surveyors, structural/electrical/civil engineers, veterinarians, environmental/public-health specialists, fire engineers, or food-safety authorities.
