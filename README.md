# Self-Sufficient Eco Farm

A master-planning and implementation repository for a **5.5-hectare (55,000 m² / 592,016 ft²) self-sufficient eco-farm** designed for Bangladesh tropical monsoon conditions.

The project combines food crops, fodder, vegetables, greenhouse production, orchards, livestock, poultry, perimeter-canal aquaculture, renewable energy, biogas, wastewater treatment, crop processing, cold storage, security, flood/cyclone resilience, and family living in one controlled ecosystem.

## Core planning basis

- Land: **250 m × 220 m = 55,000 m²**
- Approximate area: **592,016 ft² = 13.59 acres**
- No separate central fish pond
- Continuous perimeter canal for fish + flood retention + irrigation reserve + fire water
- Main clean gate + separate service/emergency gate
- Clean and dirty traffic/wastewater systems remain separated
- Fodder-first animal capacity
- Rooftop solar + battery + biogas backup
- On-site rice/feed processing, grain storage, cold chain, workshop, seed bank, silage and hay reserves

## How to work in this repository

For any significant task, read `AGENTS.md`, then use the relevant linked skills from `.agents/README.md`. Blueprints and generated images must preserve the approved 250 m × 220 m planning frame and must not invent centimeter-level accuracy that is not yet approved.

## Engineering boundary

The repository is the project’s planning/design authority, not a substitute for licensed surveyors, structural/civil/electrical engineers, veterinarians, fire engineers, environmental/public-health specialists, or food-safety authorities.
