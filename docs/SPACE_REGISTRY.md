## Fixed adjacency rules

- Wall → inspection strip → canal → inner bank → fire/service road → internal zones.
- House/admin/playground must connect to the main clean gate without crossing manure traffic.
- Livestock/poultry must connect to the service gate and biogas/treatment system.
- Processing hub must connect to crop harvest routes and service/heavy-vehicle routes.
- Food crops must remain in a no-tall-obstruction solar zone.
- Orchard tall trees must be placed away from critical crop-sunlight edges.
- Energy/water control must be above flood level and near major utility corridors.
- Quarantine must have independent controlled access and drainage.
- No raw wastewater may connect to the canal.

## Coordinate workflow

Before exact CAD/image coordinates are declared:
1. Complete legal/boundary survey.
2. Complete topographic levels.
3. Freeze road/canal/wall control lines.
4. Fit all zone polygons and verify area totals.
5. Approve coordinate register.
6. Only then allow centimeter/mm-accurate building and utility placement.

Any skill asked for exact coordinates before Step 5 must return a provisional layout clearly marked `PROVISIONAL`.
